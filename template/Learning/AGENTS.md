# Learning space

Own source-backed learning only. Read [[Learning]] and [[Rules]] before
processing material. Use `doc-learning` or `video-learning` only when the pack
is installed in `Learning/.agents/skills/`.

## Read and write boundaries

- Preserve originals in `Raw/`; never silently rewrite evidence.
- Distill into Courses, Concepts, Recall, or Open Questions. Mark inference,
  automation, and uncertainty clearly.
- Keep generated reports in `Outputs/`; they are not the canonical knowledge.
- Do not write company policy, project plans, or video concepts here. Link to
  their owning space only with explicit user approval.

For a new source, first identify provenance and the intended outcome. Preview a
large synthesis before creating many pages.
