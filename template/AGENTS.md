# Vault router

This vault is organized as agent spaces. Work from the smallest folder that
owns the task, then read that folder's `AGENTS.md` before changing knowledge.

- `Learning/` owns source-backed learning and its local learning packs.
- `Work/` owns company and project operating knowledge.
- `Studio/Video/` owns video research, concepts, and review.
- `System/` owns templates, boundaries, and navigation rules.

Do not load unrelated space documents “just in case.” Do not write across a
space boundary without an explicit user request and the receiving space's
rules. Keep durable facts in their canonical page; do not use this router as a
fact store.
