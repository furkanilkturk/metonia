# Learning Rules

- Treat `Raw/` as evidence. Preserve source text, location, date, and access
  restriction; do not replace it with a summary.
- Separate a source claim, your interpretation, and an illustrative example.
- Update an existing concept when it owns the idea instead of making duplicates.
- A concept's `Project applications` section may compare how named projects use
  it. Keep each project-specific rule separate, link back to its owning Work
  contract/evidence, and never promote one implementation into a universal rule.
- Add only links that improve retrieval; a dense graph is not a goal.
- Mark low-confidence extraction and unanswered questions explicitly.
- Keep course pages teachable and recall pages testable.
- Never ingest a source you are not authorized to store in this vault.
