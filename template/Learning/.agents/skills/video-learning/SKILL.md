# Video Learning

Work inside the current Learning agent space and follow its `AGENTS.md`. Keep
media ingestion separate from the Studio/Video production workflow.

## Workflow

1. Capture title, creator, URL, publication date when known, and transcript
   provenance. Prefer supplied or platform captions; fetching tools are optional.
2. Spot-check several transcript passages against the media. Mark automatic or
   uncertain text as unverified.
3. Inspect existing courses and concepts, then present a compact write proposal.
   Include source placement, merge/new decisions, reusable concepts, recall
   prompts, and open questions.
4. Write only after approval unless the current request already authorizes the
   full ingest.
5. Preserve the cleaned transcript under `Raw/Sources/`; keep lessons and
   concepts distilled. Add timestamps to claims where they materially aid review.
6. Connect lesson, concepts, recall, and questions with useful `[[wikilinks]]`.
7. Report changed files, transcript confidence, and the passages or timestamps
   used for verification.

If code appears on screen, label reconstructions as non-verbatim. Label invented
examples as illustrative. Never present either as source material. Do not store
unauthorized media, restricted transcripts, secrets, or private customer data.
